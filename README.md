# Facebook Clone Website

This project is a Facebook-inspired website clone that I created as part of my frontend development practice. The main goal of this project was to improve my understanding of HTML and CSS by recreating the familiar layout and design of a popular social media platform.

## 📌 About the Project

This website replicates the basic look and feel of Facebook's login page, including its blue-and-white color scheme, logo styling, login form, buttons, and overall page layout. I created this project to practice building a clean, user-friendly, and visually appealing web interface.

## 🚀 Features

- **Facebook-Inspired Design:** A familiar layout inspired by Facebook's login page.
- **Login Form:** Input fields for email address or phone number and password.
- **Interactive Buttons:** Styled login and account creation buttons with hover effects.
- **Responsive Layout:** CSS media queries to help the page adapt to different screen sizes.
- **Clean UI:** Simple typography, spacing, colors, and shadows for a polished appearance.
- **Footer Section:** Includes sample language options and footer links to complete the layout.

## 🛠️ Technologies Used

- **HTML5:** Used to structure the webpage and create the login form.
- **CSS3:** Used for styling, layout, colors, hover effects, shadows, and responsive design.

## 🎯 What I Learned

While creating this project, I practiced:

- Structuring webpages using semantic HTML elements.
- Using CSS Flexbox to align and position elements.
- Styling input fields, buttons, and containers.
- Applying hover effects and transitions to improve the user interface.
- Using media queries to make the layout more responsive.
- Understanding how to recreate an existing website's visual design for practice.

## 💻 How to Run the Project

1. Clone this repository to your local machine.
2. Open the project folder in Visual Studio Code.
3. Open the HTML file in your browser, or use the Live Server extension.
4. Explore the page and its design.
